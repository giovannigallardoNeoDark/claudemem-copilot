Política de privacidad del proyecto

SoportePrivacidadTérminos

Datos tratados

El agente consulta un snapshot controlado de ClaudeMem que puede contener decisiones, lecciones, hallazgos e historial técnico autorizado. El servicio se diseñó para acceso de solo lectura.

Credenciales

Las claves, tokens y secretos no deben almacenarse en este sitio ni incorporarse al paquete público. La autenticación del servicio MCP se administra separadamente.

Registros técnicos

El servicio puede generar registros operativos mínimos para diagnóstico, como fecha, estado de ejecución y errores técnicos. No se deben publicar datos sensibles en el repositorio.

Publicación

Las páginas de GitHub Pages son públicas. No se debe cargar información confidencial, personal o propietaria en este repositorio.

Contacto

Las consultas pueden registrarse en GitHub Issues.

Esta política corresponde al proyecto de desarrollo ClaudeMem Copilot y no sustituye políticas corporativas oficiales.
