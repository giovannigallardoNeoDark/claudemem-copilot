Términos de uso del proyecto

SoportePrivacidadTérminos

Uso permitido

ClaudeMem Copilot se proporciona para consultar antecedentes técnicos autorizados. Las respuestas deben verificarse antes de utilizarlas en decisiones operativas, técnicas o administrativas.

Limitaciones

  • El agente no garantiza que la información esté completa o actualizada fuera del snapshot publicado.
  • El agente no debe utilizarse para revelar secretos, credenciales o información no autorizada.
  • El acceso puede interrumpirse durante pruebas, mantenimiento o cambios del endpoint MCP.

Responsabilidad del usuario

La persona usuaria debe respetar las políticas de acceso, clasificación de información y seguridad aplicables al entorno donde se utilice el agente.

Cambios

Estos términos pueden actualizarse conforme evolucione el proyecto. La fecha de actualización se muestra al final de la página.

Estos términos corresponden al proyecto de desarrollo ClaudeMem Copilot y no constituyen términos corporativos oficiales de terceros.
