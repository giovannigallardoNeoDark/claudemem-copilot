# ClaudeMem Potenciado

Sistema local de memoria gobernada y contexto trazable para Copilot.

## Inicio

Ejecutar `Iniciar-ClaudeMem-Copilot.cmd` desde la raiz de `Copilot`.

## Estado actual

- Captura automatica: desactivada.
- Auditoria previa: obligatoria.
- Memoria oficial: decisiones, lecciones y hallazgos gobernados.
- Memoria episodica: sesiones, observaciones, resumenes y candidatos.

## Operacion segura

1. Escribir una consulta en el panel.
2. Seleccionar nivel 1, 2 o 3.
3. Generar contexto.
4. Revisar ID, fuente y clasificacion.
5. Exportar solo cuando corresponda.

No usar `-OmitirAuditoriaPrevia` fuera de pruebas internas.
